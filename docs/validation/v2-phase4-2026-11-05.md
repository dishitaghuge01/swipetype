## Findings and fixes

### Split dependency resolution

Namcap identified missing `makedepends`: package-specific dependencies are not
available when makepkg resolves its initial build requirements. The recipe now
includes the external dependency union. The core archive still has no GTK/WebKit
runtime dependency. Package-specific runtime arrays remain narrow.

### Active virtualenv contaminating package prefixes

This agent's `python` resolved to the checkout `.venv/bin/python`, not system
Python. The first dependency build succeeded but produced a wrong payload under
`home/dishita/swipetype/.venv/` inside the archive. **It was never installed.**

That artifact was quarantined at:

```text
/tmp/swipetype-rejected-package-ppO0wb/python-locate-1.1.1-1-any.pkg.tar.zst
```

Both local dependency recipes now explicitly use `/usr/bin/python` for builds,
checks and installation. Their `pkgrel` is 2. App checks also use system Python.
For third-party recipes and validation tools, use a clean subprocess environment:

```bash
env -u VIRTUAL_ENV -u PYTHONHOME -u PYTHONPATH PATH=/usr/bin:/bin makepkg ...
```

This does not alter the checkout's venv or its running services.

### Working-directory import isolation

The first dependency-resolved app build passed the original empty-cwd payload
check. Strengthening that check with an unrelated cwd `config.py` reproduced a
failure: the daemon prepended `.` to `sys.path` and imported the unrelated file.
It now anchors private imports to `__file__`'s directory. A focused regression
and the actual archive check both cover this case. The earlier r31 candidates
were not installed and are superseded by the corrected r34 build below.

### Generated package artifacts in test discovery

Placing built archives in `packaging/` exposed a separate test bug: globbing
`swipetype-*` caused `.pkg.tar.zst` archives to be passed to `sh -n`. Discovery
now selects extensionless shell launchers and has a regression fixture containing
an archive and service file. This fix is separate from the daemon import change.
